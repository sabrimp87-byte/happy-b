# happy-b
 Regalo web de cumpleaños interactivo para Alex ("Café con Leche"). Estética japonesa, sobria, elegante (negro, borgoña, dorado). Incluye: portada con validación graciosa, perfil editable, cuadrícula de 15 mains, reproductor de audio, test interactivo con análisis absurdo y final con confeti y carta.
